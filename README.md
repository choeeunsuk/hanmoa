# 한모아 (Hanmoa)

한글(HWP) 파일까지 다룰 수 있는 무료 PDF 도구 모음입니다.

**한** 글, 그리고 하나로 · **모아** 모으다 — 여러 문서를 한데 모으는 일이 이 앱의 시작이었습니다.

PDF 병합·분할·압축·서명·글자인식 같은 작업은 **브라우저 안에서** 끝납니다. 파일이 서버로 올라가지 않습니다.
여기에 상용 PDF 사이트에 없는 기능이 하나 더 있습니다 — **한글 문서 여러 개를 한 번에 하나의 PDF로 병합**하는 기능입니다.

---

> 📘 **[사용설명서 PDF 내려받기](docs/한모아_사용설명서.pdf)** — 설치부터 문제 해결까지 8쪽으로 정리했습니다.
> 동료에게 전달하실 때 이 파일을 함께 주시면 됩니다.

## 도구 28개

### 한글·오피스 *(로컬 엔진 필요)*
| 도구 | 하는 일 |
|---|---|
| 한글 파일 병합 | HWP·HWPX·워드·PDF·이미지를 순서대로 하나의 PDF로. 파일명으로 목차 자동 생성 |
| 문서를 PDF로 | 한글·워드·엑셀·PPT를 원본 서식 그대로 |

이미지를 PDF로 · PDF를 이미지로 · **스캔 문서 글자 인식(OCR)** · **카메라로 스캔** · PDF를 Word로 · PDF를 Excel로 · PDF를 PowerPoint로 · 웹페이지를 PDF로

### 편집

## 어떻게 쓰나요

### 1. 전부 다 쓰기 (Windows)

준비물: **Windows + 한컴오피스(한글)** · Python 3.9 이상
워드·엑셀·PPT 변환까지 쓰려면 Microsoft Office도 필요합니다.

```
start.bat 더블클릭
```

처음 한 번만 필요한 구성요소를 자동 설치하고 브라우저가 열립니다. 창을 닫으면 엔진이 종료됩니다.

첫 실행 때 **바탕화면에 «한모아» 바로가기가 자동으로 만들어집니다.**
다음부터는 그것만 누르면 됩니다. 지우면 다시 만들지 않습니다.

### 2. 설치 없이 쓰기

`web` 폴더를 정적 호스팅에 올리면 됩니다 (GitHub Pages 등). 서버가 필요 없습니다.

```bash
cd web && python -m http.server 8000
```

> `index.html` 을 브라우저로 직접 여는 방식(`file://`)은 동작하지 않습니다.
> 브라우저 보안 정책상 `file://` 에서는 워커 스크립트를 불러올 수 없습니다.

### 무엇이 어디서 도나요

| | 브라우저만으로 | 로컬 엔진이 있을 때 |
|---|---|---|
| PDF 정리·편집·압축·암호·비교·내용지우기 | ✅ | ✅ |
| 글자 인식(OCR) · 카메라 스캔 | ✅ | ✅ |
| **한글(HWP) → PDF 병합** | ❌ | ✅ |
| 워드·엑셀·PPT → PDF | ❌ | ✅ |
| PDF → Word·Excel·PPT | ❌ | ✅ |
| 웹페이지 → PDF | ❌ | ✅ |
| PDF/A 변환 | ❌ | Ghostscript 설치 시 |

앱이 로컬 엔진을 자동으로 찾습니다. 없으면 해당 도구만 잠기고 나머지는 그대로 동작합니다.

## 알아두면 좋은 것들

**한글 병합** — 문서를 하나씩 한컴오피스에 넘겨 PDF로 바꾼 뒤 이어붙입니다. 각 문서가 독립된 PDF라서 **항상 새 페이지에서 시작**하고, 파일 이름으로 **목차(북마크)** 가 만들어집니다. 문서당 2~5초.
DRM(문서 보안)이 걸린 한글 파일은 열 수 없습니다.

**내용 지우기** — 검은 사각형을 덧그리는 방식이 아닙니다. 그렇게 하면 글자가 그대로 남아 복사·검색으로 읽힙니다. 칠을 한 쪽은 통째로 그림으로 다시 구워 **가린 내용이 실제로 사라집니다**. 대신 그 쪽은 글자 검색이 되지 않습니다.

**글자 인식(OCR)** — Tesseract를 WebAssembly로 브라우저에서 돌립니다. 한국어·영어 학습 데이터를 함께 담아 인터넷 없이도 됩니다. 결과는 원본 그림 아래에 투명한 글자층이 깔린 PDF라, 보기엔 그대로인데 Ctrl+F로 찾을 수 있습니다.

**PDF/A** — Ghostscript가 필요합니다. 없으면 앱이 안내합니다. ([내려받기](https://ghostscript.com/releases/gsdnld.html))

**웹페이지 → PDF** — 이미 설치된 Chrome이나 Edge를 조용히 빌려 씁니다. 별도 브라우저를 내려받지 않습니다.
용지 크기·방향 설정은 **올린 HTML 파일에만** 적용됩니다. 주소로 받은 페이지는 그 페이지의 인쇄 설정을 따릅니다.

## 구조

```
Hanmoa/
├─ web/                 정적 프론트엔드 — 이것만으로도 대부분의 도구가 동작한다
│  ├─ index.html
│  ├─ css/style.css
│  ├─ js/
│  │  ├─ brand.js       앱 이름과 문구 (이름을 바꾸려면 여기만)
│  │  ├─ core.js        PDF 작업의 실제 구현
│  │  ├─ backend.js     로컬 엔진 감지와 통신
│  │  ├─ ui.js          파일 목록·드래그 정렬·옵션 패널·진행 창
│  │  ├─ pages.js       쪽 단위 작업 공간 (페이지 정리)
│  │  ├─ editor.js      쪽 위 편집기 (서명·글자·내용지우기) + 서명 패드
│  │  ├─ ocr.js         글자 인식
│  │  ├─ scan.js        카메라 스캔
│  │  ├─ tools.js       도구 목록 — 여기에 추가하면 화면에 바로 나온다
│  │  └─ app.js         라우팅과 실행 흐름
│  └─ vendor/           라이브러리·학습데이터 동봉 (약 13MB, 오프라인 동작용)
├─ server/              선택적 로컬 엔진 (Windows 전용)
│  ├─ main.py           API 엔드포인트
│  ├─ worker.py         작업을 하나씩 처리하는 직렬 큐
│  ├─ converter.py      한글·오피스 → PDF
│  └─ exporters.py      PDF → Word·Excel·PPT·PDF/A, 웹페이지 → PDF, 복구
└─ start.bat            원클릭 실행
```

### 도구 하나 더 붙이기

`web/js/tools.js` 의 `TOOLS` 배열에 항목을 추가하면 끝입니다. 받을 파일 형식과 설정 항목을 적고
`run()` 에서 `[{ blob, name }]` 을 돌려주면 카드·옵션 패널·진행 창이 알아서 만들어집니다.
`workspace: 'pages' | 'canvas' | 'camera'` 를 주면 해당 작업 화면을 씁니다.

## 개인정보

- PDF 작업과 글자 인식은 전부 브라우저 안에서 처리합니다. 파일이 네트워크로 나가지 않습니다.
- 한글·오피스 변환은 **내 컴퓨터에서 도는** 엔진이 처리합니다. 엔진은 `127.0.0.1` 에만 열려 있어
  같은 네트워크의 다른 컴퓨터도 접근할 수 없습니다.
- 변환에 쓴 임시 파일은 작업 후 자동 삭제됩니다.
- 카메라로 찍은 사진은 브라우저 메모리에만 있고, PDF로 만든 뒤 사라집니다.
