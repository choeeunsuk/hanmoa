웹으로 바로 쓰기

즐겨찾기에 넣어 두시면 편합니다.

왜 한글 병합만 웹에서 안 되나요?

한글 문서를 PDF로 바꾸려면 컴퓨터에 설치된 한컴오피스를 직접 불러야 합니다. 그런데 브라우저는 보안 때문에 웹사이트가 내 컴퓨터의 프로그램을 마음대로 실행하지 못하게 막습니다. 그래서 이 기능만 내 컴퓨터에서 돌리는 프로그램이 필요합니다.

2웹에서 도구 쓰는 법

모든 도구가 같은 방식으로 동작합니다. 한 번만 익히면 28가지를 다 쓰실 수 있습니다.

  1. 첫 화면에서 도구를 고릅니다 PDF 병합, 분할, 압축처럼 하시려는 일이 카드로 나열되어 있습니다.
  2. 파일을 끌어다 놓거나 «파일 선택»을 누릅니다 여러 개를 한 번에 올릴 수 있는 도구도 있습니다.
  3. 오른쪽 «설정»에서 원하는 대로 맞춥니다 그대로 두셔도 됩니다. 대부분 기본값이 무난합니다.
  4. 빨간 버튼을 누릅니다 처리가 끝나면 파일이 자동으로 저장됩니다.

자주 쓰는 도구

PDF 병합 — 여러 PDF를 하나로

파일을 올린 뒤 카드를 마우스로 끌어 순서를 바꿀 수 있습니다. 카드 왼쪽 위 번호가 합쳐질 순서입니다. «파일 이름으로 목차 만들기»를 켜두면 완성된 PDF 왼쪽에 목차가 생겨 문서 사이를 오가기 편합니다.

페이지 정리 — 순서 바꾸기 · 회전 · 삭제를 한 화면에서

PDF를 올리면 모든 쪽이 펼쳐집니다. 각 쪽 아래 단추로 돌리거나 뺄 수 있고, 쪽을 끌어서 순서를 바꿉니다. 잘못 건드렸으면 «되돌리기»를 누르면 처음으로 돌아갑니다.

스캔 문서 글자 인식(OCR) — 검색되는 PDF로

스캔한 PDF나 사진을 올리면 글자를 읽어냅니다. 결과물은 겉보기엔 원본과 같지만 Ctrl + F 로 단어를 찾을 수 있고 복사도 됩니다. 글씨가 작거나 흐리면 «인식 해상도»를 «정확»으로 올려 보세요.

내용 지우기 — 개인정보를 진짜로 삭제

가릴 곳을 마우스로 끌어 상자를 그리면 됩니다.

검은 사각형을 덧그리는 것과 다릅니다

다른 프로그램에서 검은 네모를 얹는 방식은 글자가 그대로 남아 있어 복사하면 읽힙니다. 한모아는 그 쪽을 통째로 그림으로 다시 만들어 가린 내용이 실제로 사라집니다. 대신 그 쪽은 글자 검색이 되지 않습니다.

서명 넣기 — 결재란에 이름을

오른쪽 칸에 마우스로 서명을 그린 뒤 «이 서명 사용»을 누르고, 문서에서 넣을 자리를 클릭합니다. 넣은 뒤에는 끌어서 옮기고 모서리를 잡아 크기를 바꿉니다. 도장 이미지 파일을 올려서 쓰셔도 됩니다.

3내 컴퓨터에 설치하기

한글(HWP) 병합을 쓰시려면 이 과정이 필요합니다. 처음 한 번만 하면 됩니다.

준비물

Windows · 한컴오피스(한글) — 한글 문서를 PDF로 바꾸는 데 필요합니다
워드 · 엑셀 · PPT 변환까지 쓰시려면 Microsoft Office도 있어야 합니다.

1단계 — 파일 내려받기

  1. 아래 주소로 들어갑니다
    https://github.com/choeeunsuk/hanmoa
  2. 초록색 «Code» 단추 → «Download ZIP» 화면 오른쪽 위에 있습니다.
  3. 내려받은 ZIP 파일의 압축을 풉니다 바탕화면이나 문서 폴더 등 원하는 곳에 푸시면 됩니다.
압축 풀기 전에 하면 좋은 것

내려받은 ZIP 파일에 마우스 오른쪽 → 속성을 누르면 아래쪽에 «차단 해제» 체크칸이 보일 때가 있습니다. 체크하고 «확인»을 누른 뒤 압축을 푸시면, 나중에 «Windows가 PC를 보호했습니다» 같은 경고가 뜨지 않습니다.

2단계 — Python 설치

한모아를 돌리는 데 쓰이는 무료 프로그램입니다. 이미 설치되어 있다면 3단계로 넘어가세요.

  1. python.org 에 들어갑니다
    https://www.python.org/downloads/
  2. 노란색 «Download Python» 단추를 누릅니다
  3. 내려받은 설치 파일을 실행합니다
  4. 설치 첫 화면 맨 아래를 꼭 확인하세요
    ☑ Add python.exe to PATH
    이 체크칸을 반드시 켜고 «Install Now»를 누르세요.
    이것을 놓치면 설치하고도 한모아가 Python을 찾지 못합니다. 그때는 Python을 지우고 처음부터 다시 설치해야 합니다.

Python을 설치했는데도 못 찾는다면

원인은 대개 둘 중 하나입니다.

가) «Add python.exe to PATH»를 체크하지 않았다

Python을 지우고 다시 설치하면서 그 체크칸을 켜세요. (3장 2단계 참고)

나) Windows의 껍데기 python이 가로막고 있다

Windows에는 진짜 Python이 없어도 python.exe 라는 이름만 있는 껍데기가 들어 있습니다. 실행하면 Microsoft Store만 열립니다.

  1. «설정»을 엽니다 시작 단추 → 톱니바퀴
  2. «앱 실행 별칭»을 검색해 들어갑니다
  3. python.exe 와 python3.exe 를 끕니다
  4. python.org에서 다시 설치합니다

3단계 — 실행

  1. 압축을 푼 폴더에서 start.bat 을 더블클릭합니다
  2. «Windows의 PC 보호» 경고가 뜨면 «추가 정보» → «실행»을 누르세요. 처음 한 번만 나옵니다.
  3. 검은 창이 열리고 구성요소를 자동으로 설치합니다 2~3분 걸립니다. 이때만 인터넷이 필요합니다.
  4. 브라우저가 저절로 열립니다 안 열리면 주소창에 localhost:8765 를 입력하세요.
검은 창을 닫지 마세요

그 창이 한모아를 돌리고 있습니다. 닫으면 사이트도 함께 꺼집니다. 최소화해 두세요. 다 쓰신 뒤에는 닫으시면 됩니다.

다음부터는 start.bat 을 더블클릭하면 바로 열립니다. 설치 과정은 다시 거치지 않습니다.

4한글 파일 병합하기

이 프로그램을 만든 이유입니다. 한글 문서 여러 개를 하나의 PDF로 묶습니다.

  1. 첫 화면 «한글·오피스»에서 «한글 파일 병합»을 누릅니다 화면 오른쪽 위 표시가 초록색 «엔진 연결됨»이어야 합니다.
  2. 한글 파일들을 끌어다 놓습니다 HWP, HWPX는 물론 워드·PDF·이미지도 섞어서 넣을 수 있습니다.
  3. 카드를 끌어 합쳐질 순서를 정합니다 카드 왼쪽 위 번호가 순서입니다.
  4. «한글 파일 병합» 단추를 누릅니다 문서 하나당 2~5초 걸립니다. 진행 상황이 화면에 표시됩니다.

이렇게 만들어집니다

항목 내용
서식 한컴오피스가 직접 변환하므로 표·수식·글맵시가 원본 그대로 나옵니다.
쪽 나눔 각 문서가 항상 새 쪽에서 시작합니다. 앞 문서의 마지막 쪽이 비어 있어도 뒤 문서가 이어붙지 않습니다.
목차 파일 이름으로 목차(북마크)가 자동으로 만들어집니다. PDF 왼쪽 패널에서 문서 사이를 오갈 수 있습니다.
DRM(문서 보안)이 걸린 한글 파일은 열 수 없습니다

보안 문서는 한컴오피스가 자동 변환을 거부합니다. 한글에서 파일을 열어 «다른 이름으로 저장»으로 보안을 푼 뒤 사용해 주세요.

문서를 여는 창이 잠깐씩 보일 수 있습니다

한글 프로그램을 불러 변환하기 때문입니다. 작업이 끝나면 저절로 정리됩니다. 변환 중에 한글 프로그램을 따로 조작하지 마세요. 이미 열어 두신 한글 문서는 영향을 받지 않습니다.

5잘 안 될 때

사이트가 열리지 않습니다 (연결이 거부되었습니다)

검은 창이 꺼져 있는 것입니다. start.bat 을 다시 더블클릭하세요. 인터넷·와이파이 문제가 아닙니다. 한모아는 내 컴퓨터 안에서만 통신하므로 인터넷이 없어도 동작합니다.

한글 도구가 잠겨 있습니다

화면 오른쪽 위 표시를 보세요.

표시뜻
엔진 연결됨 (초록)정상입니다. 모든 도구를 쓸 수 있습니다.
웹판 (회색)웹 주소로 들어오셨습니다. 한글 병합은 설치가 필요합니다.
엔진 없음 (회색)검은 창이 꺼져 있습니다. start.bat 을 실행하세요.

변환이 멈출 때 (진행 표시가 안 넘어감)

한글이나 Office 를 불러 변환하는 도중 그 프로그램이 응답을 멈추는 일이 있습니다. 한모아는 시간이 지나치게 걸리면 스스로 중단하고 어떤 파일에서 멈췄는지, 한글이 어떤 창을 띄웠는지까지 알려주므로 무한정 기다리게 되지는 않습니다.

첫 문서가 느린 것은 정상입니다

한글을 처음 띄우는 데만 30초가 넘게 걸리기도 합니다. 한모아는 한글을 한 번만 띄워 여러 문서를 연달아 처리하므로, 두 번째 문서부터는 몇 초면 끝납니다. 문서가 많아도 기다리는 시간이 비례해서 늘지는 않습니다.

상황해결 방법
화면에 한글 창이 떠 있다 확인 대화상자가 답을 기다리는 중입니다. 그 상자에 답한 뒤 다시 시도하세요.
창은 없는데 계속 멈춘다 한글이 굳은 상태입니다. 컴퓨터를 다시 시작하면 대부분 풀립니다.
특정 파일에서만 멈춘다 그 파일을 한글에서 직접 열어 «다른 이름으로 저장»으로 새로 저장한 뒤 넣어 보세요.
작업 관리자에서 확인하기

Ctrl+Shift+Esc 를 눌러 작업 관리자를 열고 Hwp.exe 가 남아 있으면 «작업 끝내기»로 정리한 뒤 다시 시도하세요. 한모아는 자기가 띄운 한글만 정리하므로, 여러분이 직접 열어 둔 한글 문서는 건드리지 않습니다.

«설치에 실패했습니다» 라고 나옵니다

같은 폴더의 진단.bat 을 더블클릭하면 무엇이 막혔는지 알려줍니다. [4] 패키지 서버 접속 시험 부분을 보세요.

6내 문서는 안전한가요

파일이 인터넷으로 전송되지 않습니다

PDF 작업과 글자 인식은 모두 브라우저 안에서 처리됩니다. 한글·오피스 변환은 내 컴퓨터에서 도는 프로그램이 처리합니다. 어느 쪽이든 문서가 외부로 나가지 않습니다.

항목내용
업로드 없습니다. 서버에 파일을 보내지 않습니다.
접근 범위 프로그램은 127.0.0.1(내 컴퓨터 자신)에만 열립니다. 같은 네트워크의 다른 컴퓨터도 접근할 수 없습니다.
임시 파일 변환에 쓴 임시 파일은 작업이 끝나면 자동으로 지워집니다.
인터넷 처음 설치할 때만 필요합니다. 그 뒤로는 인터넷 없이 동작합니다.
회원가입 없습니다. 개인정보를 수집하지 않습니다.
